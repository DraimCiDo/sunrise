# Deliberate content declaration changes

Within a stable line, a patch or minor release keeps every entry of the content corpus loading as it did
([release flow](release-flow.md#stable-releases)). A release that changes one on purpose lists it here, one line per
release and entry, and the release check copies the lines into that release's notes:

```
- `<release tag>` `<corpus entry>`: <what changes for a mod, and why>
```

Aria and umceko decide each line.

No release has changed an entry.
