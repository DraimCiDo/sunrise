# Deliberate content declaration changes

Within a stable line, a patch or minor release loads every entry of its parent release's content corpus as the
parent did ([release flow](release-flow.md)). A release that changes one on purpose is approved by umceko and Aria
in the break-glass environments and records each changed entry here, one line per release and entry; the release
check copies the lines into that release's notes:

```
- `<release tag>` `<corpus entry>`: <what changes for a mod, and why>
```

No release has changed an entry.
